# Real-Time-FaceMesh

Real-time Face Mesh Detection using Python, OpenCV and MediaPipe.

## 🚀 Features
- Real-time face landmark detection
- Face mesh & contour visualization
- Webcam-based live tracking
- Customized mesh styling

## 🛠️ Tech Stack
- Python
- OpenCV
- MediaPipe

## ▶️ Installation

pip install mediapipe opencv-python

## ▶️ Run the Project

python main.py


## 📸 Output
This project detects facial landmarks in real time and creates a dynamic face mesh using webcam input.
